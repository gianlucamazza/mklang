# Response form

Operator copy-paste. One block per reader. Then one register row in the
protocol's own columns. **Do not send this page to a reader.**

Use roles, not names. Write the first question verbatim.

## Per-reader block

```
# ____ / 5
Date sent:
Date of first reply:

1. Venue / person (role, not name):
2. Shown only README + agent + language recordings?  yes / no
3. Explained before the first question?              yes / no
4. First question (verbatim):

5. Understood "for"?                                 yes / no
6. Tried install within 24h?                         yes / no / (blank)

Valid protocol row?  (2 = yes AND 3 = no)            yes / no
```

If the row is not valid, keep the notes if you want, but do not count it
toward the five.

## Results-log row

Paste into the protocol's empty results register. Same columns, same order:

```
| # | Venue / person (role, not name) | First question (verbatim) | Understood "for"? | Tried install? |
| 1 |                                 |                           |                   |                |
```

Filled example of the shape only (not a real result):

```
| 1 | colleague, ships agent products | (verbatim first question here) | yes | |
```

Leave **Tried install?** empty when you did not check. The protocol marks
that column optional.

Five empty rows, matching the protocol's register as it stands:

```

```

## Headline (after the five)

Protocol line, unchanged:

```
**Headline (fill after run):** _n/5 understood · n/5 tried · branch: —_
```

Replace the two `n` figures and the em-dash after `branch:` with one of the
protocol's three named outcomes, or leave `branch:` as `—` if the counts
match none of them.
